## 1. Цель и аудитория

### 1.1. Зачем нужен сайт
Радмила проходит обучение, заказов пока не было. Сайт должен привлекать первых клиентов. В портфолио сейчас учебные проекты, со временем их заменят реальные кейсы, поэтому структура и код должны позволять заменять кейсы без переделки страницы.

**Услуги:** сайт-визитка, квиз для записи, калькулятор стоимости услуг, чат-бот, ИИ-агент.

### 1.2. Главная цель
Посетитель пишет Радмиле в Telegram (`https://t.me/radmila_direct`). Остальные каналы вторичны: кнопка «Позвонить», почта.

### 1.3. Целевая аудитория
Владельцы малого бизнеса в сфере услуг (салоны, студии, мастера, эксперты), в основном не технари. Они не знают, что такое «агент», пока не увидят его в работе. Главные вопросы такого клиента: что вы сделаете простыми словами, сколько это стоит, как быстро, что если не понравится, кому принадлежит сайт, что будет после запуска.

### 1.4. Критерии успеха
- Посетитель за 10 секунд понимает: кто, что делает, для кого и как связаться.
- Страница честно показывает учебный статус работ и при этом вызывает доверие через живые демо.
- Метрики (проверяются в Lighthouse на мобильном профиле): LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1.
- Рабочие конверсионные действия: клик в Telegram, запуск калькулятора, запуск демо-бота, клик «Открыть» на кейсе.

### 1.5. Не-цели и анти-цели
Не делать (на первом релизе):
- Форму заявки с сервером и хранением данных.
- Реальный ИИ-бэкенд: демо-бот работает по заготовленному сценарию. **[Claude]**
- Многоязычность: только русский. **[Claude]**
- Loader, кастомный курсор, перехват скролла (Lenis), 3D/WebGL: убраны по результатам экспертной оценки (research.md, раздел 4).
- Выдуманные отзывы, логотипы клиентов, цифры «100+ проектов».

Анти-цель: красивый сайт, который тормозит на телефоне, прячет текст за анимацией или выглядит как «обёртка без содержания».

## 3. Дизайн

### 3.1. Настроение
Современный, спокойный, уверенный. Тёмно-зелёный «глубокий» фон, мятный акцент, лёгкая крупная типографика, белые скруглённые карточки поверх. Референс заказчика: концепт ByteHire от Halo Lab ([Dribbble](https://dribbble.com/shots/24340514-Websites-Examples-Halo-Lab), третий слайд, тёмно-зелёное видео). Из него берём: палитру, плавное проявление текста из размытия, смену секций «как кадры» (зелёная → белая → чёрная). Копировать макет или контент ByteHire нельзя, берём только настроение.

### 3.2. Цвета (примерные, подбираются при вёрстке)

| Роль | Цвет |
|---|---|
| Фон, глубина | `#031C12` |
| Градиент, карточки на тёмном | `#0B4A2E`, `#05301F` |
| Акцент (кнопки, цифры, ссылки) | `#3DF08A` |
| Текст на тёмном | `#EAF6EE` |
| Светлые блоки | `#F2FBF6`, `#E9FBF1` |
| Текст на светлом | `#0A1C14` |
| Чёрный блок (FAQ) | `#000000` |

Контраст: обычный текст не ниже 4,5:1, крупный не ниже 3:1. Мятный текст на тёмном фоне проверить. Мятный на светлом фоне использовать только как заливку кнопок с тёмным текстом.

### 3.3. Типографика
- Заголовки: Manrope, лёгкое начертание (300), крупно, `clamp()`, `text-wrap: balance`.
- Основной текст: Manrope 400/600, не меньше 16 px на мобильном.
- Лейблы, цифры, теги: JetBrains Mono, капсом, с разрядкой.
- Не больше двух семейств.

### 3.4. Анимации
1. **Hero.** Заголовок появляется построчно из размытия и сдвига (`opacity`, `transform`, `filter: blur`), потом подзаголовок, кнопки и карточка демо-бота. Один раз при загрузке.
2. **Появление блоков при прокрутке.** CSS scroll-driven animations (`animation-timeline: view()`) под `@supports`, запасной вариант на IntersectionObserver для браузеров без поддержки (Firefox). Базовое состояние элемента **видимое**.
3. **Смена секций.** Фон секций меняется зелёный → светлый → чёрный → зелёный плавным градиентным переходом. Без перехвата скролла.
4. **Микроанимации.** Hover и focus на кнопках и карточках, плавное раскрытие FAQ.
5. Анимируются только `transform`, `opacity`, `filter`. Всё отключается при `prefers-reduced-motion: reduce`, контент остаётся видимым.
